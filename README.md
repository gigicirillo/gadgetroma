# GadgetRoma SEO landing pages

31 landing HTML organizzate nei cluster Corporate, PA/MePA e Prodotti. Tutte hanno CTA finale verso `/preventivo/` e linking interno contestuale.

## Sitemap e dominio

La sitemap da inviare in Google Search Console è [sitemap.xml](https://gigicirillo.github.io/gadgetroma/sitemap.xml), nella proprietà con prefisso URL `https://gigicirillo.github.io/gadgetroma/`. Contiene 38 URL canonici, inclusi il preventivo e la directory delle categorie. I link interni sono relativi, anche nelle landing.

Gli URL assoluti nei canonical, nei metadati Open Graph, nei dati strutturati e nella sitemap devono usare il dominio pubblico che serve queste pagine. Al passaggio al dominio definitivo, aggiornare questi riferimenti e la riga `Sitemap:` di `robots.txt`, quindi inviare la sitemap dalla proprietà del nuovo dominio. Il file robots.txt è interpretato dai crawler dalla radice dell’host.
